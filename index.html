01为什么是雨崩

藏在梅里雪山深处的藏族村落，徒步者的朝圣地，国庆中秋正逢最美秋色。

🍂

最佳季节

10月初雨崩进入金秋，层林尽染，梅里雪山日照金山概率高。避开7-8月雨季塌方，避开12-3月严冬封山。国庆正是窗口期。

🏔

三大经典线路

冰湖(3900m冰川海子)、神瀑(3600m朝圣地)、尼农大峡谷(出沟野路线)。三条线风格各异，组合成完整雨崩体验。

⚡

强度评估

中等偏上。单日累计爬升可达1000m，最高点冰湖3900m。需有高原徒步经验，非入门级。慢字当头，量力而行。

⚠️

国庆人潮

雨崩近年被网红化，国庆住宿紧张，飞来寺、上雨崩观景房需提前1个月订。早出发可避开大部队。

🚌

交通入口

飞丽江(2400m)或香格里拉(3300m)，班车至德钦，再拼车至飞来寺、西当徒步起点。香格里拉更近，丽江更稳妥。

📱

信号与补给

雨崩村内移动信号弱，电信略好；冰湖、神瀑、尼农途中无信号。下载离线地图(两步路/OutdoorActive)，带足现金。

02路线总览

尼龙线进沟，先下雨崩再上雨崩，6-7天行程节点串联。

🗺 7天经典版（推荐）· 尼龙进沟

香格里拉 → 德钦 → 飞来寺(日照金山) → 格阁家饭店(起点) → 尼龙线进沟 → 下雨崩村 → 神湖 → 神瀑 → 上雨崩村 → 尼色线 → 冰湖 → 返程

🗺 6天紧凑版

香格里拉 → 飞来寺 → 格阁家饭店 → 尼龙进沟 → 下雨崩+神瀑 → 上雨崩+冰湖 → 返程
6天版说明：压缩神湖/尼色线，只走神瀑+冰湖核心两线。D3尼龙进沟当天住下雨崩，D4神瀑+转场上雨崩，D5冰湖，D6返程。强度大，仅适合体力强者。推荐7天版，从容安全。

03五条经典徒步线 + 尼龙进沟

雨崩徒步核心路线，按行程顺序排列。神湖/尼色为可选线，择机选择。

🥾 尼龙线·进沟

海拔 2100→3080m · 15km · 爬升1000m · 5-6h
  • 西当停运后成为进雨崩主要入口
  • 格阁家饭店为起点，尼农村出发
  • 前段悬崖栈道，后段原始森林
  • 全程上坡，进沟比出沟护膝
  • 景色比西当线更野更美
安全：悬崖栈道窄，雨后易落石。骡子过人贴山壁让行。

🏔 神湖线

海拔 4500m · 往返 · 爬升1500m · 6-8h
  • 下雨崩出发，全程野路无补给
  • 可近距离看神女峰
  • 雨崩最接近雪山的一条线
  • 全程最难之一，仅限体力强者
  • 带足水和干粮
高难可选：爬升1500m，状态差果断放弃。

💧 神瀑线

海拔 3600m · 往返6km · 爬升500m · 4-5h
  • 下雨崩出发，最易的一条线
  • 藏传佛教朝圣地，绕瀑3圈祈福
  • 水汽大，必带雨衣冲锋衣
  • 可挂经幡，垭口风大
  • 文化氛围浓厚，肃穆
文化提示：保持肃穆，顺时针绕瀑，不喧哗，不手指神山。

🌿 尼色线

海拔 4400m · 往返16km · 爬升1500m · 7-8h
  • 上雨崩出发，经尼色河牧场
  • 至尼色拉古垭口有冰洞可探
  • 比冰湖更长更野，人少景幽
  • 途中可能有野生岩羊
  • 全程野路，无补给
注意：尼色拉古垭口4400m，高反立即下撤。冰洞勿深入。

❄️ 冰湖线

海拔 3900m · 往返12-14km · 爬升700m · 6-7h
  • 上雨崩出发，经笑农大本营补给
  • 冰川融水形成的翠绿色海子
  • 背后是卡瓦格博冰川，震撼
  • 雨崩最经典的一条线
  • 晴天上午光线最佳
切勿靠近冰湖边缘，冰层可能塌陷。

04村落与住宿

雨崩分上雨崩、下雨崩，住宿选择直接影响体验，国庆务必提前1个月预订。

飞来寺

海拔 3400m · 雨崩前哨

看梅里日照金山的最佳位置，10月初日出约7:00-7:30。建议住1晚，选正对雪山的观景房。

价格：¥300-800/晚，国庆翻倍。

观景房必选 提前1个月订 日照金山

上雨崩

海拔 3160m · 冰湖出发地

看神女峰、五冠峰的最佳位置，视野比下雨崩开阔。去冰湖从这里出发最近。建议住2晚。

价格：¥300-600/晚。

观景房 冰湖起点 住2晚

下雨崩

海拔 3080m · 神瀑出发地

更靠近神瀑入口，村落更幽静。从上雨崩徒步下来约40分钟。建议住1-2晚。

价格：¥300-500/晚。

神瀑起点 更幽静 住1-2晚

尼农村

海拔 2000m · 出沟终点

尼农大峡谷徒步终点，从这里拼车回德钦。一般不停留，直接出沟。

价格：¥150-300/晚(若需停留)。

出沟终点 拼车点
预订建议：飞来寺1晚 + 上雨崩2晚 + 下雨崩1晚 = 4晚村落住宿，国庆务必9月初前订完。让老板确认是否含早晚餐、是否有热水洗澡、是否正对雪山。雨崩村内餐食价格是县城2-3倍，含餐客栈更划算。

057天详细行程

推荐版本，节奏从容，留出天气缓冲。6天版见路线总览。

DAY 1
抵达香格里拉，适应海拔
海拔 3300m
路线：出发地 ✈ 香格里拉(3300m)

当日安排

  • 建议直飞香格里拉，比丽江更接近雨崩，省次日车程。
  • 若担心高反，飞丽江(2400m)更稳妥，但次日车程多4小时。
  • 抵达后不剧烈运动，慢走、多喝水、早休息。
  • 香格里拉可逛独克宗古城，转世界最大转经筒。
  • 晚上整理装备，检查徒步鞋、冲锋衣、保暖中层。

住宿

  • 独克宗古城附近客栈，¥200-400/晚。
高反预防：提前3-5天服红景天(效果因人而异)，携带高原安。第一天剧烈头痛、呕吐需警惕，可吸氧或下撤。
DAY 2
香格里拉 → 德钦 → 飞来寺
海拔 3400m
路线：香格里拉 🚌 德钦(4h) 🚌 飞来寺(1.5h)

上午

  • 香格里拉客运站乘班车至德钦，每天2-3班，建议早班(约7:30)。
  • 沿途经金沙江大拐弯、白马雪山垭口(4292m)，景色壮丽。

下午

  • 德钦换乘拼车至飞来寺，约1小时，¥30-50/人。
  • 入住飞来寺观景客栈，选正对梅里雪山的房间。
  • 傍晚可在观景台拍梅里日落，主峰卡瓦格博6740m。

住宿

  • 飞来寺观景客栈：¥300-800/晚，国庆提前1个月订。
🌕 中秋赏月：2026年中秋在10月X日(查当年日历)，若D2恰逢中秋，飞来寺观景台赏月+梅里雪山是绝配。带相机脚架，月光下的卡瓦格博极为圣洁。
日照金山：日出约7:00-7:30(10月初)，需晴天。云雾天看不到。住1晚看运气，住2晚概率更高。本行程仅1晚，建议提前查7天天气预报。
DAY 3
飞来寺 → 格阁家饭店 → 尼龙线进沟 → 下雨崩村
海拔 2100→3080m · 入沟
路线：飞来寺 🚐 格阁家饭店(起点) 🥾 尼龙线(15km，爬升约1000m，5-6h) 🥾 下雨崩村

清晨

  • 6:30起床观日照金山(若天气好)，7:30前出发。
  • 飞来寺拼车至尼农村格阁家饭店(徒步起点)，约1.5小时，¥50-80/人。
  • 格阁家饭店可吃早餐、补给，最后的热饭热菜点。

徒步：尼龙线进沟

  • 从格阁家饭店出发，沿尼农峡谷进沟，全程15km，爬升约1000m，预计5-6小时。
  • 前段沿水渠走悬崖栈道，一边崖壁一边深渊，恐高者慎行。
  • 过秘境客栈约一半路程，可补给休息。
  • 后段过雨崩河桥，进入原始森林，缓上至下雨崩村。
  • 全程上坡为主，慢字当头，每走30-40分钟休息5分钟。

下午

  • 抵达下雨崩村，入住客栈，放下行李。
  • 下雨崩是神瀑、神湖的出发点，接下来两天以此为基地。

住宿

  • 下雨崩客栈：¥300-500/晚，国庆务必提前订。推荐「雪龙客栈」(做菜好吃)。
安全提示：尼龙线悬崖栈道窄，雨后易落石塌方。若前一晚下雨或当日阴雨，建议推迟或改走西当进沟。看见骡子过来人贴山壁内侧让行。
为什么走尼龙进沟：西当越野车停运后，尼龙线成为进雨崩的主要入口。上坡进沟比下坡出沟更安全(出沟伤膝)，且景色更野。进沟住下雨崩，顺路走神瀑神湖，再上雨崩走冰湖尼色。
DAY 4
下雨崩 → 神湖线（高难·可选）→ 下雨崩
最高海拔 4500m
路线：下雨崩 🥾 神湖(往返，爬升1500m，6-8h) 🥾 下雨崩

全天：神湖线

  • 从下雨崩出发，全程爬升约1500m，最高海拔4500m，往返6-8小时。
  • 可近距离看到神女峰，是雨崩最接近雪山的一条线。
  • 全程野路，无补给点，需带足水和干粮。
  • 全程最难的一条线，仅适合体力好、有高原经验者。

备选：跳过神湖

  • 若体力不足或高反，可跳过神湖，改为休整+短逛下雨崩周边。
  • 下雨崩旁有大草原，天气好可看雪山尖尖，适合拍照发呆。
  • 也可将D4改为神瀑线(最易)，D5转场上雨崩走冰湖。
高难预警：神湖线爬升1500m，最高4500m，是雨崩6条线中难度最高的之一。若前两天高反明显，果断放弃，安全第一。神湖可远观不可强求。
择机选择：神湖线为可选路线，建议根据D3进沟后身体状态决定。状态好多爬，状态差跳过，不影响后续行程。
DAY 5
下雨崩 → 神瀑线 → 下雨崩 → 转场上雨崩
海拔 3600m
路线：下雨崩 🥾 神瀑(往返6km，爬升500m，4-5h) 🥾 下雨崩 🥾 上雨崩(2km上坡，40min)

上午：神瀑朝圣

  • 从下雨崩出发，沿神瀑河谷上行，往返约6km，爬升500m，4-5小时。
  • 神瀑是藏传佛教朝圣地，传说绕瀑3圈可洗罪祈福。
  • 可携带经幡挂在垭口(当地可买)。
  • 神瀑水汽大，必带雨衣或冲锋衣，手机相机做好防水。
  • 全程水泥路+石板路，是雨崩最易的一条线，作为热身刚好。

下午：转场上雨崩

  • 回到下雨崩退房，徒步至上雨崩，约2km，40分钟，全程上坡。
  • 上雨崩是冰湖、尼色的出发点，接下来以此为基地。
  • 入住上雨崩观景客栈，选正对梅里雪山的房间。

住宿

  • 上雨崩客栈：¥300-600/晚。推荐「觉色酥油茶客栈」(做菜好吃)。
文化提示：神瀑是藏族神山朝圣点，保持安静肃穆，不大声喧哗、不用手指直指神山。绕瀑按顺时针方向。
DAY 6
上雨崩 → 尼色线（可选）→ 上雨崩
最高海拔 4400m
路线：上雨崩 🥾 尼色河牧场 🥾 尼色拉古垭口(4400m) 🥾 上雨崩(往返16km，爬升1500m，7-8h)

全天：尼色线

  • 从上雨崩出发，经沙棘林、笑农曲河，至尼色河牧场补给点。
  • 继续上行至尼色拉古垭口(约4400m)，有冰洞可探。
  • 全程往返16km，爬升约1500m，7-8小时。
  • 比冰湖线更长更野，人少景幽，途中可能有野生岩羊。

备选：跳过尼色

  • 若体力不足，可跳过尼色，D6改为休整或短逛上雨崩观景台。
  • 也可将D6与D7合并：上午尼色(走一半折返)，下午冰湖。
  • 上雨崩观景台可拍神女峰、五冠峰日落金山。
注意：尼色线全程野路，爬升大，仅适合体力好者。尼色拉古垭口4400m，若高反立即下撤。冰洞内温度极低，勿深入。
择机选择：尼色线为可选路线。若决定走尼色+冰湖两条，建议D6尼色(先难后易)，D7冰湖。若只走一条，选冰湖(更经典)。
DAY 7
上雨崩 → 冰湖线 → 上雨崩 → 出沟 → 返程
最高海拔 3900m · 出沟
路线：上雨崩 🥾 冰湖(往返12-14km，爬升700m，6-7h) 🥾 上雨崩 🚐 德钦 → 返程

上午：冰湖线

  • 8:00出发，轻装上阵(只带当日补给)。
  • 途经笑农大本营(夏季牧民放牧点)，可补给热水、泡面。
  • 过笑农后爬升加大，最后1km陡升到冰湖垭口。

冰湖

  • 海拔约3900m，冰川融水形成的翠绿色海子，背后是梅里雪山冰川。
  • 湖边风大温度低，加穿保暖层，停留拍照30-40分钟即下撤。
  • 切勿靠近冰湖边缘冰层，曾有塌陷事故。

下午：出沟返程

  • 原路返回上雨崩，预计15:00-16:00到村。
  • 退房后拼车出沟至德钦(原路尼龙返回，或西当出沟)。
  • 德钦班车回香格里拉(4h)，香格里拉飞返程。
  • 若航班在次日，可在香格里拉再住一晚。
装备：登山杖必带(下坡护膝)、保暖中层、雨衣、2L水、能量补给。
返程缓冲：D7是徒步+交通双重日，建议返程航班选在傍晚或次日。若遇天气延误，D8可作缓冲日。
路线：德钦 🚌 香格里拉(4h) ✈ 返程

当日安排

  • 德钦早班车回香格里拉，约4小时。
  • 香格里拉机场飞返程，或夜班车/动车回丽江飞。
  • 若航班在次日，可在香格里拉再住一晚，逛松赞林寺。
  • 若从丽江进出，德钦→丽江约8-9小时，建议在香格里拉中转一晚。
缓冲提示：D7是交通日，若遇班车取消或天气延误，建议返程航班选在傍晚或次日，预留缓冲。雨崩期间若天气差导致某天线路取消，D6/D7可灵活调整。
